# Portuguese, Brazil (`pt-BR`)

Brazilian Portuguese follows Apple's conventions in macOS Mail and AppKit for `pt_BR` for address, label form, capitalization, punctuation and the ellipsis. It is the only Portuguese catalog, so it reads as Brazilian, never European. Its words follow two rules:

- **An OS label takes its platform's word.** An entry whose `msgctxt` is `macOS`, `Windows` or `Linux` is a label the operating system names its own way, such as the File menu or Paste. A label only macOS shows, such as the Window menu or Hide Others, is an OS label too and carries `macOS` alone. `macOS` takes Apple's word (Apple Mail's for a mail menu item), `Windows` Microsoft's and `Linux` GNOME's, from [Platform words](#platform-words) below. Only the word changes: address, capitalization, punctuation and the ellipsis stay this sheet's on every platform, so a Windows or Linux label is title-cased too.
- **Everything else takes the house word**, from this sheet and the glossary: Meru's own copy reads the same on every platform. Where Chrome has a term, its Brazilian Portuguese translation is the house word, unless this sheet says otherwise. A term Gmail also shows takes Gmail's word from the glossary.

Where this sheet and a habit from other software disagree, this sheet wins.

## Address

_você_, with _seu_ and _sua_: _Tem certeza de que deseja …?_, _sua conta_. Never _tu_ or its verb forms (_queres_, _tens_). Chrome addresses the user the same way.

## Buttons and menu items

The infinitive: _Responder_, _Excluir_, _Salvar_, _Cancelar_, _Fechar Guia_. Delete is _Excluir_, as Chrome and Gmail write it, never _Apagar_.

## Capitalization

Title case for menu items and buttons, as Apple writes them: every word except articles, prepositions and conjunctions takes a capital (_Nova Mensagem_, _Marcar como Lida_, _Fechar Outras Guias_). Chrome's sentence-case labels are its own style and are not followed. Sentences, descriptions and dialog text are sentence style. A label that opens something further ends in an ellipsis with no space before it: _Adicionar Conta…_.

## Settings

_Configurações_, Chrome's word, in Meru's own copy: the window, its title and every mention of it. The app-menu item with `msgctxt` `macOS` is Apple's _Ajustes…_, as AppKit writes it; with `Windows` or `Linux` it is _Configurações_, Microsoft's and GNOME's word, without the ellipsis the English lacks. _Ajustes_ appears in Meru's own copy only as macOS's own _Ajustes do Sistema_.

## Access keys

An `&` in the English marks the access key on Windows and Linux. Keep one `&` inline, before a letter of the Portuguese word: the English's letter where the Portuguese has it, otherwise a free one. Two labels in the same menu never share a letter. macOS drops the `&`. Chrome's own letters are not followed. The context menu's labels, with their keys, the same on Windows and Linux except where noted:

- `Cu&t` _Recor&tar_, `&Copy` _&Copiar_, `&Paste` _Co&lar_, `Select &All` _Selecion&ar Tudo_
- `Paste and &Match Style` _Colar com a &Mesma Formatação_ on Windows, _Colar com o &Mesmo Estilo_ on Linux
- `&Learn Spelling` _Ap&render Ortografia_, `&Search with Google` _Pe&squisar com o Google_
- `Sa&ve Image As…` _Sal&var Imagem Como…_, `Copy Lin&k` _Copiar Lin&k_, `Cop&y Image` _Copiar &Imagem_, `C&opy Image Address` _C&opiar Endereço da Imagem_

## Plural categories

`one`, `many` and `other`. `one` covers 0 and 1 in Brazilian Portuguese, `many` is for large round numbers (1.000.000), so its text is usually the same as `other`'s: `{count, plural, one {# guia} many {# guias} other {# guias}}`.

## Terms that stay English

Gmail, Google Workspace, Meru, Meru Pro and Pro. They take Portuguese articles outside the word: _o Gmail_, _o Meru Pro_.

## Traps

- **Brazilian, not European.** _arquivo_, _tela_, _baixar_, _usuário_, gerund (_Baixando…_); never _ficheiro_, _ecrã_, _transferir_, _utilizador_ or _a baixar_. Chrome's Brazilian Portuguese agrees on every one.
- **Punctuation.** Quotation marks are “…” (U+201C, U+201D), as Apple writes them, never straight `"…"`, which Chrome mostly uses. The ellipsis is the single character …, never three periods.
- **Numbers and units.** A plain space joins a number to its unit, as Chrome writes it: _5 minutos_, _# dias_.
- **Placeholders and articles.** _o_, _a_, _do_ and _da_ change with the value. Put the placeholder after a noun (_a conta {name}_).
- **Gendered forms.** Rewrite around the person rather than use _o(a)_.
- **House words, as Chrome writes them.** A tab is a _guia_, never an _aba_: _Fechar Guia_, _guias verticais_, the tab strip the _barra de guias_. To delete is _excluir_. To pin a tab is _fixar_ and to unpin it _liberar_. To quit is _sair_ (_Sair_); the app menu's Quit is an OS label, Apple's _Encerrar {appName}_ on macOS. To search is _pesquisar_ and a search a _pesquisa_ (_pesquisa salva_), never _buscar_ or _busca_ outside Apple's own `macOS` labels. An email is an _e-mail_, with the hyphen. A bookmark is a _favorito_, an extension an _extensão_, a link a _link_, a website a _site_. The download history is the _histórico de downloads_, the launcher the _iniciador_, the default browser the _navegador padrão_, a password manager a _gerenciador de senhas_ and a passkey a _chave de acesso_. Restarting is _reiniciar_ and an update an _atualização_. The `pt-BR.json` rules beside this sheet give Chrome's count for each.

## Error messages

Say what happened, without _Desculpe_ or _Por favor_: _Não foi possível adicionar a conta._, as Apple writes _Não foi possível renomear essa caixa de correio._

## Common labels

House words for everyday actions, from Chrome's Brazilian Portuguese where it has the label and Apple's Mail and AppKit where it does not, in this sheet's title case. A string that names something Gmail also shows, such as the Undo button in the message-sent toast, takes Gmail's word from the glossary instead, and an entry with a platform `msgctxt` takes [its platform's word](#platform-words):

- Cancel _Cancelar_, OK _OK_, Close _Fechar_, Delete _Excluir_, Remove _Remover_, Add _Adicionar_, Save _Salvar_, Edit _Editar_, Open _Abrir_, Show _Mostrar_, Hide _Ocultar_, Quit _Sair_, Reload _Recarregar_, Try Again _Tentar Novamente_, Done _Concluído_, Learn More… _Saiba Mais…_
- Close Tab _Fechar Guia_, Close Other Tabs _Fechar Outras Guias_, Pin Tab _Fixar Guia_, Unpin _Liberar_, Show Sidebar _Mostrar Barra Lateral_, Copy Link _Copiar Link_, Mark as Read _Marcar como Lida_, Add Account… _Adicionar Conta…_
- _Tem certeza de que deseja excluir esta mensagem?_ (Are you sure you want to delete this message?)
- _Até que os anexos tenham sido baixados, você não poderá arrastá-los. Deseja baixar este anexo?_

## Platform words

The word each platform uses for every label with a platform `msgctxt`. A label keeps its English placeholders and access key as the rules above say; the table gives the words, in this sheet's title case.

`pt-BR.json` beside this sheet holds the same words by `msgctxt` and `msgid`, with the banned words, pinned terms and access-key style that `check.ts` holds a catalog against. A test keeps it and this table in step: a cell's words are the italic spans that open each `;`-separated part.

Sources: **AppKit** and **Mail** are the `.loctable` files in `/System/Library/Frameworks/AppKit.framework/Versions/C/Resources` and `/System/Applications/Mail.app/Contents/Resources` on macOS 27, named by table and key, as are **Dictionary** and **Screen Sharing**, in `/System/Applications/Dictionary.app` and `/System/Applications/Utilities/Screen Sharing.app`; **Software Update** is `/System/Library/ExtensionKit/Extensions/SoftwareUpdateSettingsExtension.appex/Contents/Resources/Localizable.loctable`; all for Apple's `pt_BR`. **TBX** is the Microsoft Terminology Collection, `PORTUGUESE (BRAZIL).tbx`, by `termEntry` id; **gtk4**, **nautilus** and **gedit** (GNOME Text Editor) are GNOME's `pt_BR.po` for each, by `msgid` (and `msgctxt` where it has one). _Inferred_ marks a word no source gives for that label, built from the source words named.
