# Spanish, Latin America (`es-419`)

Latin American Spanish follows what Apple ships in macOS Mail and AppKit for `es_419`. Spain has its own catalog, `es`; the two never borrow from each other. Where this sheet and a habit from other software disagree, this sheet wins.

An entry whose `msgctxt` is `macOS`, `Windows` or `Linux` is an OS label, a label each operating system names its own way, such as the File menu or Paste. `macOS` takes Apple's word (Apple Mail's for a mail menu item), `Windows` Microsoft's and `Linux` GNOME's. Only the word changes: this sheet's address, capitalization and punctuation hold on every platform.

## Address

_tú_, with _tu_ and _te_: _¿Quieres …?_, _tu cuenta_. Never _vos_, _ustedes_ or _usted_.

## Buttons and menu items

The infinitive, as in `es`: _Responder_, _Eliminar_, _Guardar_, _Cancelar_, _Cerrar pestaña_. The confirming button is _OK_, not _Aceptar_, and Settings is _Configuración…_.

## Capitalization

Sentence style: only the first word and proper nouns take a capital.

## Settings

_Configuración_. The app-menu item with `msgctxt` `macOS` is _Configuración…_, as AppKit writes it; with `Windows` or `Linux` it takes Microsoft's or GNOME's word, without the ellipsis the English lacks.

## Plural categories

`one`, `many` and `other`. `many` is for large round numbers (1,000,000), so its text is usually the same as `other`'s: `{count, plural, one {# pestaña} many {# pestañas} other {# pestañas}}`. 0 takes `other`.

## Terms that stay English

Gmail, Google Workspace, Meru, Meru Pro and Pro.

## Traps

- **Latin America's vocabulary and tense.** _computadora_, _ingresar_, _Agregar_, _Configuración_; the simple past: _No se pudo …_. Never Spain's _ordenador_, _introducir_, _Añadir_, _Ajustes_ or _No se ha podido …_.
- **Punctuation.** A question or exclamation opens with ¿ or ¡.
- **Placeholders and articles.** _el_, _la_ and _del_ change with the value. Put the placeholder after a noun (_la cuenta {name}_).
- **Gendered forms.** Rewrite around the person rather than use _o/a_ or _@_.

## Error messages

Say what happened, without _Lo sentimos_ or _Por favor_: _No se pudo agregar la cuenta._, as Apple writes _No se pudo renombrar el buzón “%1$@”._

## Apple's words

From Mail's `MainMenu`, `Alerts` and `Localizable` tables and AppKit's `MenuCommands`. A string that names something Gmail also shows, such as the Undo button in the message-sent toast, takes Gmail's word from the glossary instead:

- Cancel _Cancelar_, OK _OK_, Undo _Deshacer_, Close _Cerrar_, Delete _Eliminar_, Remove _Eliminar_, Add _Agregar_, Save _Guardar_, Edit _Editar_, Open _Abrir_, Show _Mostrar_, Hide _Ocultar_, Quit _Salir_, Reload _Volver a cargar_, Try Again _Reintentar_, Learn More… _Obtén detalles…_
- Close Tab _Cerrar pestaña_, Close Other Tabs _Cerrar las otras pestañas_, Close Window _Cerrar ventana_, Pin Tab _Anclar pestaña_, Show Sidebar _Mostrar barra lateral_, Minimize _Minimizar_, Copy Link _Copiar enlace_, Mark as Read _Marcar como leído_, Add Account… _Agregar cuenta…_, Quit Mail _Salir de Mail_
- _¿Seguro que quieres eliminar este mensaje?_ (Are you sure you want to delete this message?)
- _Escribiste “%@”, pero parece que olvidaste agregar un documento. ¿Quieres enviar el mensaje de todos modos?_
