# Spanish, Spain (`es`)

Spanish for Spain follows what Apple ships in macOS Mail and AppKit for `es`. Latin America has its own catalog, `es-419`; the two never borrow from each other. Where this sheet and a habit from other software disagree, this sheet wins.

## Address

_tú_, with _tu_ and _te_: _¿Seguro que quieres …?_, _tu cuenta_. Never _vosotros_ or _usted_.

## Buttons and menu items

The infinitive: _Responder_, _Eliminar_, _Guardar_, _Cancelar_, _Aceptar_, _Cerrar pestaña_. The confirming button is _Aceptar_, not _OK_.

## Capitalization

Sentence style: only the first word and proper nouns take a capital.

## Settings

_Ajustes_; the app-menu item is _Ajustes…_.

## Plural categories

`one`, `many` and `other`. `many` is for large round numbers (1.000.000), so its text is usually the same as `other`'s: `{count, plural, one {# pestaña} many {# pestañas} other {# pestañas}}`. 0 takes `other`.

## Terms that stay English

Gmail, Google Workspace, Meru, Meru Pro and Pro.

## Traps

- **Spain's vocabulary and tense.** _ordenador_, _introducir_, _Añadir_, _Ajustes_; the perfect for a recent past: _No se ha podido …_. Never Latin America's _computadora_, _ingresar_, _Agregar_, _Configuración_ or _No se pudo …_.
- **Punctuation.** A question or exclamation opens with ¿ or ¡.
- **Placeholders and articles.** _el_, _la_ and _del_ change with the value. Put the placeholder after a noun (_la cuenta {name}_).
- **Gendered forms.** Rewrite around the person rather than use _o/a_ or _@_.

## Error messages

Say what happened, without _Lo sentimos_ or _Por favor_: _No se ha podido añadir la cuenta._, as Apple writes _No se ha podido renombrar el buzón “%1$@”._

## Apple's words

From Mail's `MainMenu`, `Alerts` and `Localizable` tables and AppKit's `MenuCommands`. A string that names something Gmail also shows, such as the Undo button in the message-sent toast, takes Gmail's word from the glossary instead:

- Cancel _Cancelar_, OK _Aceptar_, Undo _Deshacer_, Close _Cerrar_, Delete _Eliminar_, Remove _Eliminar_, Add _Añadir_, Save _Guardar_, Edit _Editar_, Open _Abrir_, Show _Mostrar_, Hide _Ocultar_, Quit _Salir_, Reload _Volver a cargar_, Try Again _Reintentar_, Learn More… _Más información…_
- Close Tab _Cerrar pestaña_, Close Other Tabs _Cerrar el resto de pestañas_, Close Window _Cerrar ventana_, Pin Tab _Anclar pestaña_, Show Sidebar _Mostrar barra lateral_, Minimize _Minimizar_, Copy Link _Copiar enlace_, Mark as Read _Marcar como leído_, Add Account… _Añadir cuenta…_, Quit Mail _Salir de Mail_
- _¿Seguro que quieres eliminar este mensaje?_ (Are you sure you want to delete this message?)
- _Para arrastrar un archivo adjunto, primero debes descargarlo. ¿Quieres descargar el archivo adjunto?_
