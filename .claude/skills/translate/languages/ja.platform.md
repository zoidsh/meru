# ja: platform words

The word each platform uses for every label with a platform `msgctxt`. A label keeps its English placeholders, and its access key as [ja.md](ja.md) says; the table gives the words, without access keys.

The table is written from `ja.json` beside this sheet, whose `platformWords` rows give each word with its source and the entries it settles by `msgctxt` and `msgid`; the sidecar also holds the banned words, pinned terms, access-key style and key-name casing that `check.ts` holds a catalog against. Change a word in the sidecar, never here, then run `bun .claude/skills/translate/platform-table.ts ja`; a test fails while the two differ.

Sources: **AppKit** and **Mail** are the `.loctable` files in `/System/Library/Frameworks/AppKit.framework/Versions/C/Resources` and `/System/Applications/Mail.app/Contents/Resources` on macOS 27, named by table and key, as are **Dictionary** and **Screen Sharing**, in `/System/Applications/Dictionary.app` and `/System/Applications/Utilities/Screen Sharing.app`; **Software Update** is `/System/Library/ExtensionKit/Extensions/SoftwareUpdateSettingsExtension.appex/Contents/Resources/Localizable.loctable`; **TBX** is the Microsoft Terminology Collection, `JAPANESE.tbx`, by `termEntry` id; **gtk4**, **nautilus** and **gedit** are GNOME's `ja.po` for each, by `msgid` (and `msgctxt` where it has one). _Inferred_ marks a word no source gives for that label, built from the source words named. **WebKit** is `/System/Library/Frameworks/WebKit.framework/Versions/A/Frameworks/WebCore.framework/Versions/A/Resources/<language>.lproj/Localizable.strings`, the page context menu Safari shows, by key; a context-menu item with an access key and no platform `msgctxt` on Windows and Linux takes the house word there, and its `macOS` entry takes WebKit's.
