# pt-BR: platform words

The word each platform uses for every label with a platform `msgctxt`. A label keeps its English placeholders and access key as [pt-BR.md](pt-BR.md) says; the table gives the words, in this sheet's title case.

The table is written from `pt-BR.json` beside this sheet, whose `platformWords` rows give each word with its source and the entries it settles by `msgctxt` and `msgid`; the sidecar also holds the banned words, pinned terms and access-key style that `check.ts` holds a catalog against. Change a word in the sidecar, never here, then run `bun .claude/skills/translate/platform-table.ts pt-BR`; a test fails while the two differ.

Sources: **AppKit** and **Mail** are the `.loctable` files in `/System/Library/Frameworks/AppKit.framework/Versions/C/Resources` and `/System/Applications/Mail.app/Contents/Resources` on macOS 27, named by table and key, as are **Dictionary** and **Screen Sharing**, in `/System/Applications/Dictionary.app` and `/System/Applications/Utilities/Screen Sharing.app`; **Software Update** is `/System/Library/ExtensionKit/Extensions/SoftwareUpdateSettingsExtension.appex/Contents/Resources/Localizable.loctable`; all for Apple's `pt_BR`. **TBX** is the Microsoft Terminology Collection, `PORTUGUESE (BRAZIL).tbx`, by `termEntry` id; **gtk4**, **nautilus** and **gedit** (GNOME Text Editor) are GNOME's `pt_BR.po` for each, by `msgid` (and `msgctxt` where it has one). _Inferred_ marks a word no source gives for that label, built from the source words named. **WebKit** is `/System/Library/Frameworks/WebKit.framework/Versions/A/Frameworks/WebCore.framework/Versions/A/Resources/pt.lproj/Localizable.strings`, the page context menu Safari shows, by key; a context-menu item with an access key and no platform `msgctxt` on Windows and Linux takes the house word there, and its `macOS` entry takes WebKit's. WebKit's `pt` is Brazilian, beside its `pt_PT`.
